🛒 E-Commerce App (React + Firebase)

This is a front-end clone of an e-commerce site built using *React* and powered by the *Fake API from Platzi*. It includes product listings, authentication, cart functionality, and checkout flow.

---

🔗 [View Deployed Site on Vercel](https://e-commerce-mu-six-17.vercel.app/)

 📦 GitHub Repository

---

 🚀 Features

- ✅ Product listing with images, titles, prices, 
- ✅ Product detail page
- ✅ Add to cart functionality
- ✅ Cart page with quantity adjustment and delete
- ✅ Firebase user authentication (Login/Register)
- ✅ Mock checkout
- ✅ Responsive UI

---

 🛠️ Tech Stack

- React (Frontend)
- React Router DOM
- Firebase (Authentication)
- Bootstrap (Styling)
- Platzi Fake Store API: [https://api.escuelajs.co/api/v1/products](https://api.escuelajs.co/api/v1/products)
- Vercel (Deployment)

 🧑‍💻 How to Run Locally

 1. Clone the repo

bash
git clone https://github.com/your-username/e_commerce.git
cd e_commerce_

*Setup Firebase
Create a Firebase project at firebase.google.com

Replace your Firebase config inside src/FirebaseConfig/firebaseConfig.js
const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_DOMAIN",
  ...
};
Start the development server 
npm start
